# پنل مدیریت آکام ماشین

پنل در مسیر `/admin/*` و به‌صورت lazy-loaded اجرا می‌شود. رابط فارسی و RTL است و برای نمایشگرهای کوچک، منوی کناری جمع‌شونده دارد.

## اجرا

در ریشه پروژه:

```powershell
npm install
npm run dev
```

آدرس ورود: `http://localhost:5173/admin/login`

## حساب‌های آزمایشی

- مدیر: `admin@akam.local` / `admin123`
- ویرایشگر: `editor@akam.local` / `editor123`

این حساب‌ها فقط برای محیط Mock هستند. در انتشار عمومی حتماً احراز هویت واقعی و مدیریت نشست از API استفاده شود. داده‌های تغییر یافته پنل در localStorage مرورگر با پیشوند `akam-admin-` باقی می‌مانند. برای پاک‌سازی داده‌های آزمایشی می‌توان کلید `akam-admin-store-v1` را از Local Storage مرورگر حذف کرد.

## حالت Mock و API واقعی

فایل `.env`:

```env
VITE_API_URL=http://localhost:8000/api
VITE_USE_MOCK=true
```

برای اتصال به بک‌اند:

1. مقدار `VITE_USE_MOCK=false` شود.
2. `VITE_API_URL` به آدرس API محیط موردنظر تنظیم شود.
3. قرارداد `docs/ADMIN_API_CONTRACT.md` با تیم Laravel نهایی شود.
4. پاسخ‌های endpointها با envelopeهای تعریف‌شده در قرارداد منطبق شوند.
5. ورود Bearer token و خطاهای 401/422 در تست یکپارچه بررسی شوند.

صفحات از `useAdminResource` و `adminClient` استفاده می‌کنند؛ بنابراین برای اتصال اولیه، تغییر در صفحات لازم نیست. مسیرهای endpoint و در صورت نیاز نگاشت envelopeها در `src/admin/api/client.js` متمرکز است. داده seed در `src/admin/mocks/store.js` از JSONهای چهار زبان `src/mocks` خوانده می‌شود.

## ساختار

- `AdminApp.jsx`: مسیرهای پنل
- `auth/`: ورود، نگهداری نشست، Context و محافظ مسیر
- `api/client.js`: انتخاب Mock یا HTTP و هدر Bearer
- `mocks/store.js`: داده seed، ذخیره‌سازی محلی و عملیات CRUD آزمایشی
- `features/`: داشبورد و صفحات مدیریت منابع
- `layout/`: نوار کناری و سربرگ
- `admin.css`: ظاهر واکنش‌گرا و مستقل پنل
- `docs/ADMIN_API_CONTRACT.md`: قرارداد پیشنهادی API

## کتابخانه‌ها

کتابخانه جدیدی اضافه نشده است. React Query موجود برای query، mutation و invalidation استفاده می‌شود؛ فرم‌ها با کنترل‌های بومی React پیاده‌سازی شده‌اند تا وابستگی اضافه و حجم پنل حداقلی بماند. نمودار داشبورد نیز با CSS ساخته شده است.

## نکات و محدودیت‌های این مرحله

- همه عملیات CRUD پنل در Mock انجام می‌شوند و هیچ اطلاعاتی به سرور ارسال نمی‌شود.
- نقش‌های admin و editor در UI لحاظ شده‌اند؛ کنترل دسترسی قطعی باید سمت API نیز اجرا شود.
- رسانه در Mock فقط مرجع محلی/آدرس آزمایشی است؛ آپلود واقعی باید با multipart/form-data انجام شود.
- ترجمه‌ها به‌صورت موجودیت واحد با `translations.fa/en/ru/ar` نگهداری می‌شوند؛ انتشار در هر زبان مستقل است.
- داده‌های تلفن ثابت و کدهای داخلی تا زمان تأیید منتشر نمی‌شوند. هیچ شماره‌ای از روی حدس تکمیل نشده است.
- محتوای اولیه شرکت مطابق PDF کارفرما ثبت شده: شروع فعالیت در ۱۳۹۸، کارگاه حدود ۱۰۰۰ مترمربع، ۱۰ نیروی ثابت و حدود ۲۵ نیروی پروژه‌ای و برون‌سپاری برخی عملیات تخصصی.
